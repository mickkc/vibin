# AI Contribution Policy for Vibin'

**Effective Date**: July 10, 2026

No AI-generated contributions of any kind are permitted in this project.

This includes, but is not limited to:

- Using AI tools to **write, generate, or modify** any part of the Vibin' codebase
- **Submitting pull requests** containing AI-generated code or content
- Using AI to **suggest or implement features**, bug fixes, or improvements
- Incorporating **AI-generated assets** (icons, graphics, etc.) into the project
- Using AI to **write or enhance documentation**, README files, or wiki content
- Using AI to **generate commit messages** or changelog entries
- Using AI to **analyze, refactor, or optimize** existing code in the project

Any AI-generated contributions will be rejected and removed.
